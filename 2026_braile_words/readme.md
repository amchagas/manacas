Here we are using a free tool to translate words written in latin alphabet to braille.
The idea is to put this together with the Feelipa colour code https://feelipa.com/

the tool lives here:
- https://cta-ifrs.github.io/Text2Braille3d/text2braille3d.html

The dimensions of the plates with letters should be:

6-8cm length
1.5cm height
0.5cm thickness
