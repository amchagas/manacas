this folder contains data and information about converting 2d images onto images that can be printed.
The idea is that by adding texture and surface layers we can make so that people with visual impairment 
can experience the images in a different way.

We are using open source litophane creator platforms and a FDM 3D printer to achieve this. 

At the moment, we can only do this in one colour, but the idea is to test printing in different orientations so that we can do a black on white contour for higher contrast. 

Here are some of the open source and/or free tools:

- https://github.com/muldjord/lithomaker
- https://lithobox.app/#s=box
- https://github.com/smrini/img2stl
